# Versification data

- `wlc-kjv-versemap.xml` — `wlc/VerseMap.xml` from the Open Scriptures Hebrew Bible
  (https://github.com/openscriptures/morphhb, commit `3d15126fb1ef74867fc1434be1942e837932691f`),
  CC BY 4.0, credited to the Open Scriptures Hebrew Bible Project. Unmodified copy: 1,978 verses where
  the Westminster Leningrad Codex's numbering differs from the KJV's (1,971 `full`, 7 `partial`).
- `schemes.properties` — which numbering each Bible edition follows, generated by
  `scripts/strongs/build_numbering_schemes.py` from `docs/versification-ledger.tsv`.
