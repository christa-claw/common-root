# Paths that go into the public mirror (github.com/christa-claw/common-root).
#
# Read by scripts/publish/publish_public.sh. One prefix per line, matched
# against `git ls-files` — so only TRACKED files can ever be exported; nothing
# untracked or gitignored (application-local.properties, .env, sources/, …)
# has a path to the outside. A line starting with "!" is a deny prefix and wins
# over any allow line. Order does not matter. "#" starts a comment.
#
# The rule of thumb: code and the reference documents that describe the
# system are public; deliberation (design notes, plans, session notes,
# audits, outreach and correspondence, engineering logs), other people's
# material (transcripts, the argument ledger, channel contacts, corpus
# sources) and anything machine-specific stay private. When in doubt, leave
# it out — a path can be added in a later release, never un-published.
